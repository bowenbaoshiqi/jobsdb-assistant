## User journeys

1. A new user starts JobsDB Assistant once without learning internal commands
   or identifiers.
2. A returning user resumes the same active session and unfinished work.
3. A Dashboard-created job batch reaches the Agent, changes from queued to
   running, and drains to a durable scored state.
4. Dashboard-created material tasks reach the same Agent session.
5. Candidate interview and confirmation remain explicit human gates.
6. Closing and restarting the Agent reclaims work exactly once.
7. The Skill keeps listening on idle and ends only on explicit stop or failure.
