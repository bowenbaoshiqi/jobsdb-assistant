## Release checks

The final release evidence is produced by:

```bash
uv run ruff check src/ tests/ scripts/privacy_guard.py
uv run pytest -m 'not e2e' --cov=src --cov-branch --cov-report=term-missing
uv run pytest -m e2e tests/e2e/test_dashboard_browser.py tests/e2e/test_material_dashboard_browser.py
uv run python scripts/privacy_guard.py
```

No real JobsDB application is submitted by these checks. The five
`tests/manual/jobsdb_live/` diagnostics are intentionally excluded from
pytest and require explicit foreground execution.

## PR stabilization evidence

The pre-PR full-suite run exposed a stochastic punctuation-delay failure.
The existing implementation sampled an unbounded Gaussian base delay and
applied the 20ms floor only after adding punctuation pauses, so a negative
sample could cancel the intended 0.3–0.8 second sentence pause.

| Guarantee | RED evidence | GREEN evidence |
