# v0.6.0 Closed-loop Applications — TDD Evidence

## Scope

v0.6 adds fixed-template tailored resumes and a human-approved application
execution loop:

- only Professional Summary, four Career Highlights, and three Core
  Competencies are replaced in the two-page v5 PDF;
- Work Experience and all later content and layout remain frozen;
- every approved Quick Apply package binds one PDF, one 100–300-word cover
  letter, immutable hashes, the JobsDB job, and the account;
- JobsDB remote resumes are deleted before the single job-specific PDF is
  uploaded and verified;
- preparation stops at Review and submission requires a separate Dashboard
  confirmation;
- Apply jobs remain a manual handoff.

## Manual gate

The remaining release gate is a user-driven local test on port 8877:

1. review an approved material package;
2. click prepare on one Quick Apply role;
3. verify the browser reaches Review with the exact PDF and cover letter;
4. explicitly confirm submission if desired;
5. verify submitted or intervention state after manual refresh;
6. verify an Apply role exposes PDF, cover-letter copy, and JobsDB detail
   handoff without external-site automation.
