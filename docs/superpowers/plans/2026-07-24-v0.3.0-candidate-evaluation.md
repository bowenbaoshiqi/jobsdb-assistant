# v0.3.0 Candidate & Evaluation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a resumable Python-controlled workflow that creates a confirmed, versioned candidate profile with pinned `ai-job-search` guidance and incrementally scores JobsDB snapshots with pinned native `career-ops` A–F evaluation.

**Architecture:** `jobsdb-assistant` owns a persisted SQLite workflow state machine. Claude Code or Codex starts the workflow and services typed JSON AI checkpoints; the skill cannot advance state without Python validation. External public forks are cloned at exact SHAs into ignored local directories and are never modified or automatically updated.

**Tech Stack:** Python 3.9+, Pydantic 2, Typer, Rich, SQLite, pytest, ruff, Git/GitHub CLI, Claude Code/Codex agent skills.

## Global Constraints

- Follow strict RED–GREEN–REFACTOR; production code is written only after a valid failing test and each RED/GREEN checkpoint is committed.
- Repository coverage remains at least 80%; new or materially changed application modules target at least 90%.
- `ai-job-search` only provides candidate onboarding/profile guidance.
- `career-ops` is the sole scoring source; retain native A–F output and 1.0–5.0 overall score without custom weighting, score fusion, or percentage conversion.
- Python and SQLite own workflow state, ordering, retry, caching, validation, and reports.
- Claude Code/Codex skills only start the workflow and service typed AI checkpoints.
- Do not add a model provider, direct model API, API key, daemon, scheduler, deployment, or unattended mode.
- Do not modify either fork, run `git pull`, or accept arbitrary integration URLs.
- Candidate profiles require explicit confirmation and are immutable after confirmation.
- Normal later runs reuse the active profile and exact integration checkouts without regeneration or reinstall.
- Candidate documents, AI task payloads/results, reports, SQLite data, and integration clones remain ignored.
- Preserve the five existing untracked probe scripts without editing or committing them.

APPROVED_URLS = frozenset({
    "https://github.com/bowenbaoshiqi/ai-job-search.git",
    "https://github.com/bowenbaoshiqi/career-ops.git",
})


class IntegrationSpec(BaseModel):
    url: str
    commit: str = Field(pattern=r"^[a-f0-9]{40}$")
    license: Literal["MIT"]
    contract_version: str = Field(min_length=1)
    required_paths: list[str] = Field(min_length=1)

    @field_validator("url")
    @classmethod
    def approved_url(cls, value: str) -> str:
        if value not in APPROVED_URLS:
            raise ValueError("unapproved integration URL")
        return value


class IntegrationManifest(BaseModel):
    schema_version: Literal[1]
    integrations: dict[str, IntegrationSpec]


def load_manifest(path: Path) -> IntegrationManifest:
    return IntegrationManifest.model_validate_json(path.read_text(encoding="utf-8"))

- [ ] **Step 2: Implement command-runner injection and exact-SHA checks**

Implement the core boundary:

```python
class CommandRunner(Protocol):
    def run(self, command: tuple[str, ...]) -> str: ...


class IntegrationManager:
    def __init__(
        self,
        root: Path,
        manifest: IntegrationManifest,
        runner: CommandRunner,
    ) -> None:
        self.root = root
        self.manifest = manifest
        self.runner = runner

    def check(self, integration_id: str) -> IntegrationState:
        spec = self.manifest.integrations[integration_id]
        path = self.root / integration_id
        if not path.is_dir():
            return IntegrationState(
                id=integration_id, path=path, commit=spec.commit, status="missing"
            )
        head = self.runner.run(("git", "-C", str(path), "rev-parse", "HEAD")).strip()
        if head != spec.commit:
            return IntegrationState(
                id=integration_id, path=path, commit=head, status="mismatch"
            )
        if any(not (path / required).exists() for required in spec.required_paths):
            return IntegrationState(
                id=integration_id, path=path, commit=head, status="damaged"
            )
        return IntegrationState(
            id=integration_id, path=path, commit=head, status="ready"
        )

    def install_missing(self, integration_id: str) -> IntegrationState:
        state = self.check(integration_id)
        if state.status != "missing":
            return state
        spec = self.manifest.integrations[integration_id]
        self.runner.run(("git", "clone", "--no-checkout", spec.url, str(state.path)))
        self.runner.run(
            ("git", "-C", str(state.path), "checkout", "--detach", spec.commit)
        )
        return self.check(integration_id)
```

`repair()` must reject `ready`, move only the exact named integration checkout to a
timestamped sibling backup, reinstall the locked SHA, and never delete a broad path.

class EvaluationCacheKey(BaseModel):
    model_config = ConfigDict(frozen=True)
    snapshot_hash: str = Field(pattern=r"^[a-f0-9]{64}$")
    profile_hash: str = Field(pattern=r"^[a-f0-9]{64}$")

        payload = self.model_dump_json().encode("utf-8")
