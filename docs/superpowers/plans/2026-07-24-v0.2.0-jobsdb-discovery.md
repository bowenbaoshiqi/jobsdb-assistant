# v0.2.0 JobsDB Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a non-submitting `discover` command that searches JobsDB Hong Kong for one keyword, captures at most 50 complete JDs, classifies application type, and persists incremental immutable snapshots.

**Architecture:** Extend the existing `HomepageScraper`, `JobDetailPage`, `Orchestrator`, and SQLite `Database` instead of introducing a new service framework. A pure URL builder creates the JobsDB HK search target; the scraper repeats its existing extraction after bounded scrolls; detail capture returns a focused domain value; persistence compares normalized JD hashes transactionally.

**Tech Stack:** Python 3.11+, Typer, Pydantic, Playwright behind `PageController`, SQLite, pytest/pytest-asyncio, Ruff, uv.

## Global Constraints

- Exactly one non-empty keyword per run.
- Hong Kong is fixed for v0.2; all other JobsDB filters use site defaults.
- Preserve JobsDB result order and stop at 50 unique job IDs.
- Reuse `HomepageScraper`; do not add a multi-source adapter or service process.
- `discover` must never call the application state machine.
- Full JD text and private runtime paths must not be printed.
- New SQLite changes are forward-only and non-destructive.
- Default tests do not launch a browser; live browser checks remain explicitly selected.
- Keep line-and-branch coverage at or above 80%.
- Preserve the five existing untracked `scripts/probe_*.py`/test probe files without staging them.

```python
"""JobsDB Hong Kong search input utilities."""

from urllib.parse import quote


def normalize_keyword(keyword: str) -> str:
    normalized = " ".join(keyword.split())
    if not normalized:
        raise ValueError("keyword must not be empty")
    return normalized


def build_search_url(keyword: str) -> str:
    slug = normalize_keyword(keyword).lower().replace(" ", "-")
    encoded = quote(slug, safe="-")
    return f"https://hk.jobsdb.com/{encoded}-jobs"
```

This path form is based on the current official JobsDB HK result URL
`https://hk.jobsdb.com/product-manager-jobs`. The optional live contract test detects future
site changes without putting network access in default CI.

Add private conversion/merge helpers so deduplication occurs before limiting:

```python
async def get_search_jobs(
    self,
    max_jobs: int = 50,
    no_growth_limit: int = 2,
) -> list[JobListing]:
    if max_jobs < 1:
        raise ValueError("max_jobs must be at least 1")
    if no_growth_limit < 1:
        raise ValueError("no_growth_limit must be at least 1")

    collected: dict[str, JobListing] = {}
    stagnant_rounds = 0
    while len(collected) < max_jobs and stagnant_rounds < no_growth_limit:
        before = len(collected)
        for data in await self.page.evaluate(EXTRACTION_SCRIPT) or []:
            collected.setdefault(data["id"], self._to_listing(data))
            if len(collected) == max_jobs:
                break
        if len(collected) == before:
            stagnant_rounds += 1
        else:
            stagnant_rounds = 0
        if len(collected) < max_jobs and stagnant_rounds < no_growth_limit:
            await self.page.evaluate(
                "window.scrollTo(0, document.body.scrollHeight)"
            )
            await asyncio.sleep(1.5)
    return list(collected.values())
```

Keep `get_recommended_jobs` behavior compatible, but route its data conversion through the
same `_to_listing` helper. Do not implement `Next` clicking until a live fixture proves it is
required.

Add public `discover` with the same initialize/login/cleanup envelope as `run`, then a small
loaded helper:

```python
async def discover(self, keyword: str, limit: int = 50) -> dict:
    try:
        await self._init_browser()
        if not await self._ensure_login():
            return self._create_discovery_error(keyword, "login_failed")
        return await self._discover_loaded(keyword, limit)
    finally:
        await self._cleanup()
```

`_discover_loaded` navigates to `build_search_url(keyword)`, collects listings, then for each:

- navigate with existing human simulation;
- capture detail data;
- persist and increment `new`/`unchanged`/`changed`;
- increment apply-type counts;
- catch expected per-job extraction/navigation errors and append only safe reason codes.

Do not reuse `_scrape_jobs`, build the apply queue, create an application session, or call
application tracking.
